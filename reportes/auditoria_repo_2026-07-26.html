Insights ejecutivos

1. La arquitectura territorial polimórfica es la joya del proyecto

H2 no fue un refactor cualquiera: reemplazó dos FKs (comuna, distrito) + una CheckConstraint por un solo FK unidad_territorial con jerarquía (nacional → regional → distrital → comunal). Esto abre la puerta a senadores (nivel regional), CORE (provincial) y constituyentes sin migraciones nuevas. Es exactamente lo que hace que este código sobreviva al post-tesis.

2. Fricción de bootstrap ya está bajo control

El squash de M2 baja 79 operations a 16 en fresh install. Los 25 archivos viejos siguen ahí porque Django los usa como fallback en envs existentes — es la ruta recomendada. Cuando confirmes que no queda ningún env con migraciones aplicadas antiguas, se pueden borrar y quedan 13 archivos de migración (0001_squashed + 0026-0038).

3. Tamagui está en fase terminal y no lo sabía

El repo ya tiene 27 atoms propios + 30 molecules construidos con RN puro y tokens del design system. Tamagui solo sobrevive en PasswordResetConfirmScreen.tsx por inercia. Migrar ese screen (10 minutos) desbloquea el borrado del plugin Babel, el archivo de config, ~50 paquetes en node_modules y bajar tiempo de expo start.

4. Los tests frontend son buenos pero unilaterales

64 unit tests de services puros = decisión pragmática y correcta (services testeables sin RN, feedback rápido). Pero el cuerpo del app (hooks, componentes, flujos) queda sin cobertura. Un smoke test E2E de "cuestionario completo → ver ranking" en RN Web + Playwright tapa el 80% de la superficie con pocos tests.

5. Próximos 3 pasos concretos si querés
  1. Migrar PasswordResetConfirmScreen + purgar Tamagui (1 sesión, ~30 min).
  2. Dividir NoticiasScreen y DetalleCandidatoScreen a componentes hijos (1 sesión, ~45 min).
  3. Setup Playwright + 1 smoke test del flujo cuestionario→resultados (1 sesión, ~1 h).
