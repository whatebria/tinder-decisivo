Critical C-03 getMatchColor usa 3 tiers con tokens incorrectos — DS-08 define 5 tiers de afinidad

DS-08 y DS-11 definen 5 tiers de afinidad con tokens propios (--c-aff5 a --c-aff1). getMatchColor() en services/matching.ts implementa solo 3 buckets mapeados a tokens semanticos genericos (success, warning, danger). colors.ts no exporta los tokens de afinidad. Resultado: un match del 90% muestra el verde-bosque apagado del tier 4 cuando deberia mostrar el verde vibrante (brandAccent) del tier 5.

Med M-10 confianzaToBadge duplica logica de getConfianzaBadge del service

DRY roto. La funcion no exportada en el screen repite la misma clasificacion que el service ya tiene. No es testeable. Eliminarla y agregar getConfianzaBadgeVariant() al service.

// ResultadosScreen.tsx -- BORRAR
function confianzaToBadge(confianza?: string): BadgeVariant {
  const key = (confianza ?? "TENTATIVA").toUpperCase();
  if (key === "ALTA") return "success";
  if (key === "MEDIA") return "warning";
  return "danger";
}

// services/matching.ts -- AGREGAR
export function getConfianzaBadgeVariant(confianza?: string): BadgeVariant {
  const key = (confianza ?? "TENTATIVA").toUpperCase();
  if (key === "ALTA") return "success";
  if (key === "MEDIA") return "warning";
  return "danger";
}
