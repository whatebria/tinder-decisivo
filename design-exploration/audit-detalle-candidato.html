Fase 1 · Componentes Frontend
P-M01 · useNoticiasCandidato activo cuando SHOW_NOTICIAS=false ampliar BUG-024
El mismo patron que BUG-024 (useNoticiasFeed en HomeScreen). Con SHOW_NOTICIAS=false, la tab de Noticias no aparece ni se renderiza NoticiasTab, pero el hook dispara una request HTTP en cada mount de DetalleCandidatoScreen. El usuario visita muchos perfiles en una sesion -- el costo se multiplica por N visitas.
DetalleCandidatoScreen.tsx L90: const noticiasQ = useNoticiasCandidato(candidatoId); -- sin { enabled: SHOW_NOTICIAS }
P-M02 · useFavoritos() y useDescartados() activos para usuarios guest
Para guests, ActionRow no renderiza (condicion !isGuest). Los valores isFavorito e isDescartado se calculan pero nunca se muestran. Sin embargo, useFavoritos() y useDescartados() se ejecutan incondicionalmente -- 2 requests de red por visita a cada perfil en modo guest que van directamente al garbage collector.
DetalleCandidatoScreen.tsx L93-94: const favoritosQ = useFavoritos(); const descartadosQ = useDescartados();
P-L01 · "Candidato no encontrado" no distingue error de red de candidato inexistente
El branch post-loading muestra el mismo mensaje para dos casos distintos: candidato inexistente en la API (404) y error de red (timeout, 500). En el caso de error de red, el usuario no tiene boton de retry -- solo "Volver". Un tercer case candidatoQ.isError con EmptyState y refetch() mejoraria la recuperabilidad.

Fase 11 · Justificacion
useNoticiasCandidato condicionado
El usuario visita muchos perfiles. N visitas * 1 request inutil = N requests desperdiciadas. Fix: { enabled: SHOW_NOTICIAS }. Ampliar BUG-024 en lugar de crear issue nuevo.
Favoritos/Descartados condicionados
2 requests por visita en modo guest que nunca se usan. enabled: !isGuest es 2 lineas. Reduce carga al backend y mejora tiempo de carga para usuarios no autenticados.
Error state separado (bajo)
Caso infrecuente, pero cuando ocurre el usuario queda sin salida. El fix agrega un tercer branch y un EmptyState con retry. Bajo esfuerzo, bajo urgencia.
